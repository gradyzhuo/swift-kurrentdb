# Protocol Buffer definitions

`Sources/_GRPCProtobufGenerated` is the Swift code generated from the `.proto` files in this directory: one `.pb.swift` file (messages) and one `.grpc.swift` file (client stubs) per `.proto` file. It is never edited by hand; change a `.proto` file and regenerate instead, and commit the proto change and the regenerated sources together.

## Regenerating

```bash
scripts/regenerate-protos.sh
```

The script needs `protoc` 3.15 or later on `PATH` (`brew install protobuf`; on Debian or Ubuntu `apt-get install protobuf-compiler libprotobuf-dev`, since `google/protobuf/descriptor.proto` comes with `libprotobuf-dev`), `git` and a Swift toolchain with tools version 6.1 or later (grpc-swift-protobuf 2.4.1's `Package.swift` declares `swift-tools-version:6.1`; the package itself still builds with Swift 6.0). It builds the two pinned protoc plugins into `.build/generators` the first time, then regenerates every `proto/**/*.proto` into `Sources/_GRPCProtobufGenerated` (`--output DIR` and `--generators DIR` change both places; `--help` lists them).

Pinned generators:

- `protoc-gen-swift` from [swift-protobuf](https://github.com/apple/swift-protobuf) **1.37.0**
- `protoc-gen-grpc-swift-2` from [grpc-swift-protobuf](https://github.com/grpc/grpc-swift-protobuf) **2.4.1**, built with grpc-swift-2 2.4.4 (its code generator) and swift-protobuf 1.39.0 (its plugin library) resolved exactly, since the tag does not pin them

The swift-protobuf version is the floor in `Package.swift` (`from: "1.37.0"`). Bumping either generator is one commit that runs the script and changes nothing else. CI regenerates the code with the same script and fails on any difference from the committed files.

Without the script, the two commands it runs from the repository root are:

```bash
protoc --plugin=protoc-gen-swift=<path to protoc-gen-swift> \
  --swift_out=Sources/_GRPCProtobufGenerated --proto_path=proto \
  --swift_opt=Visibility=package --swift_opt=FileNaming=PathToUnderscores \
  $(find proto -name '*.proto' | LC_ALL=C sort)
protoc --plugin=protoc-gen-grpc-swift-2=<path to protoc-gen-grpc-swift-2> \
  --grpc-swift-2_out=Sources/_GRPCProtobufGenerated --proto_path=proto \
  --grpc-swift-2_opt=Visibility=Package --grpc-swift-2_opt=Server=False --grpc-swift-2_opt=FileNaming=PathToUnderscores \
  $(find proto -name '*.proto' | LC_ALL=C sort)
```

## The `.grpc.swift` files

The `.grpc.swift` files are generated by grpc-swift-protobuf's `protoc-gen-grpc-swift-2` with `Visibility=Package`, `Server=False` (the package is a client, so no server stubs) and `FileNaming=PathToUnderscores`. A `.proto` file without a service still gets a `.grpc.swift` file that says so. These files change only when a service changes or the plugin is bumped.
